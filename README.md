Эмулятор оболочки ОС (Вариант 4) — Этап 1

 1. Общее описание
Программа представляет собой эмулятор командной строки виртуальной файловой системы (VFS) с графическим интерфейсом пользователя (GUI). На данном этапе реализован цикл REPL для ввода команд, парсер строк по пробелам, а также обработка базовых команд и ошибок.

 2. Описание всех функций и настроек
 `process_command(event)` — основная функция обработки ввода. Считывает команду, очищает поле ввода, разбивает строку по пробелам на команду и аргументы, выводит результат в окно истории.
 Графический интерфейс содержит:
  Заголовок окна: `vfs_emulator`
  Верхнее текстовое поле — история терминала (защищено от редактирования).
  Нижнее поле ввода — строка для ввода команд пользователем.

  3. Описание команд для сборки проекта и запуска тестов
Сборка проекта: Проект написан на интерпретируемом языке Python и не требует предварительной компиляции (сборки).
Запуск проекта: Для запуска дважды кликните по файлу `run.bat` в корневой папке. Внутри него вызывается команда:
  ```bash
  python src/main.py
  ```
Запуск тестов: На Этапе 1 автоматические тесты не предусмотрены (папка `tests/` пока пустая). Тестирование проводится вручную в интерактивном режиме.

 4. Примеры использования
Успешный вызов команды `ls`:** 
   Ввод: `ls documents`
   Вывод: `[Заглушка] Вызвана команда: ls, Аргументы: ['documents']`
Успешный вызов команды `cd`:** 
   Ввод: `cd projects`
   Вывод: `[Заглушка] Вызвана команда: cd, Аргументы: ['projects']`
Обработка неизвестной команды:** 
   Ввод: `unknown_cmd`
   Вывод: `Ошибка выполнения: неизвестная команда 'unknown_cmd'`
Выход из программы:** 
   Ввод: `exit`
   Результат: Графическое окно закрывается, работа завершается.
