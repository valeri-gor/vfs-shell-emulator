Этап 2

1. Общее описание
Программа представляет собой настраиваемый эмулятор командной строки виртуальной файловой системы (VFS) с графическим интерфейсом (GUI). На данном этапе реализован приём параметров конфигурации через аргументы командной строки и автоматическое выполнение стартовых скриптов с имитацией диалога пользователя.

2. Описание всех функций и настроек
 Поля конфигурации (модуль `argparse`):
   `--storage` — путь к физическому архиву файловой системы.
   `--prompt` — строка пользовательского приглашения к вводу в REPL.
   `--script` — путь к стартовому текстовому скрипту с командами.
 Основные функции:
   `process_command(cmd_text)` — выполняет команду (из интерфейса или из файла), выводит её в историю вместе с заданным `--prompt`.
   `execute_start_script()` — считывает файл скрипта, игнорирует комментарии (`#`) и автоматически выполняет команды.

3. Описание команд для сборки проекта и запуска тестов
Сборка проекта:** Не требуется (интерпретируемый язык Python).
Запуск проекта с параметрами:** Выполняется через файл `run.bat` командой:
  ```bash
  python src/main.py --storage archive.zip --prompt "valeria:> " --script tests/start.txt
  ```
Запуск тестов:** Проверка парсера из Этапа 1 выполняется командой:
  ```bash
  python -m pytest tests/
  ```

4. Примеры использования
При запуске эмулятора через `run.bat` автоматически отрабатывает скрипт `tests/start.txt`:
Ввод из скрипта:** `ls` -> **Вывод:** `[Заглушка] Вызвана команда: ls, Аргументы: []`
Ввод из скрипта:** `cd documents` -> **Вывод:** `[Заглушка] Вызвана команда: cd, Аргументы: ['documents']`
В чёрной консоли реальной ОС отображается отладочный вывод: `Запущено с параметрами: ...`
